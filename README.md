# استوديو الموشن (Nour Motion Studio)

موقع لصناعة فيديوهات موشن جرافيك من قوالب جاهزة. بيشتغل كامل جوا المتصفح:
ما في API key، ما في سيرفر، ما في اشتراك. التصدير لـ MP4 بيصير على جهاز المستخدم نفسه.

## شو فيه

- **فيديو جديد خطوة بخطوة:** المقاس، الستايل، وبعدين فكرة جاهزة أو مشاهد بتختارها بنفسك.
- **318 قالب (مشهد جاهز)** موزعة على 22 تصنيف، وكل قالب بتشوفه كبير وشغّال قبل ما تضيفه، و17 فكرة فيديو جاهزة بكبسة وحدة.
- **دمج القوالب:** أضف كمشهد، ادمج عناصره بالمشهد الحالي، أو استبدل المشهد فيه.
- **تعديل سهل:** كل نصوص المشهد بمكان واحد، كبستين على النص لتكتب فوق الفيديو، وشريط أدوات سريع فوق أي عنصر (أكبر، أصغر، لون، حركة عشوائية، نسخ، حذف).
- **217 خلفية متحركة** (73 نوع) بمكتبة فيها بحث و13 تصنيف، منها شبكة نور الحية بكل حالاتها.
- **349 انتقال** بين المشاهد بـ14 تصنيف، وبتشوف كل انتقال بين مشاهدك الحقيقية قبل ما تختاره.
- **85 حركة كاميرا** مع عمق (بارالاكس).
- **أصوات:** 86 مؤثر صوتي بيتولّد بالمتصفح، 8 ستايلات صوت، صوت لكل عنصر وانتقال، أصوات بتضيفها بأي لحظة، علو لكل نوع، وملف صوت خاص فيك (تعليق صوتي مثلاً).
- **بوستر:** احفظ أي لحظة من أي مشهد كصورة PNG أو JPG، أو خليها غلاف الفيديو.
- **20 ثيم للفيديو** (ليل، نهار، غابة، إشارة + 16 إضافي) و**وضع نهاري وليلي للموقع نفسه**.
- **مقاسات:** ريلز 9:16، لينكدإن 4:5، مربع 1:1، يوتيوب 16:9.
- **تصدير MP4** بجودة 1080 أو 720، 30 أو 60 إطار.

## التشغيل على جهازك

لازم يشتغل من سيرفر محلي (مو بفتح الملف مباشرة) لأن الكود مقسوم لموديولات:

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

## الاستضافة ببلاش

الموقع ملفات ثابتة بس (HTML و CSS و JS)، فبيشتغل على GitHub Pages أو Netlify أو Cloudflare Pages بدون أي إعداد.

## المتصفحات

- **Chrome و Edge** (كمبيوتر وأندرويد): تصدير MP4 كامل وسريع.
- **Safari و Firefox:** إذا ما دعموا الترميز، الموقع بيسجّل الفيديو بالوقت الحقيقي كـ WebM.

## إضافة قوالب جديدة

كل قالب عبارة عن مشهد مكتوب بـ JavaScript بملفات `js/templates/pack-*.js` باستخدام أدوات `kit.js`.
المواقع (`x`, `y`) نسب من الإطار، والأحجام بوحدات (1/1000 من الضلع الأقصر). بعد ما تكتب الحزمة، سجّلها بـ `js/templates/index.js`.

## ترخيص المكتبات

تصدير الفيديو بيستخدم مكتبة [Mediabunny](https://mediabunny.dev) (رخصة MPL-2.0)، ونسخة منها موجودة بـ `js/vendor`.
